# Source — Workflow Redesign Framework

| 단계 | 핵심 목적 | Core | 핵심 산출물 |
| --- | --- | --- | --- |
| **① Discover** | 업무 전체를 얕게 꺼내고 Target Work 선정 | Job Inventory + Scoping Gate | Work Inventory + Target Work |
| **② Decompose** | 실제 Task/Sub-task로 분해 | HTA | Task Tree |
| **③ Deep Dive** | 판단·지식·예외·암묵지 추출 | CTA + Evidence | Knowledge & Decision Map |
| **④ Map** | End-to-End As-Is + 기준선 | Process Mapping + Baseline | As-Is Workflow + Baseline |
| **⑤ Diagnose** | Root Cause와 개선기회 검증 | RCA + Validation | Opportunity Map |
| **⑥ Redesign** | 업무 자체 개선 후 역할 재배치 | ECRS + Human/Rule/System/AI Allocation | To-Be Workflow |
| **⑦ Build** | 실행 가능한 Prototype 구현 | SOP + Acceptance Criteria | Working Prototype |
| **⑧ Embed** | Pilot하고 효과 측정·정착 | Pilot → Measure → Iterate | Pilot Result + 적용계획 |
